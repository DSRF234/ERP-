## 新发现缺陷 BUG-03（未修）

## 新增：经营数据问答 Agent（智能取数模块）

**目标**：业务人员（运营 / 库管 / 采购）用自然语言取数，自动生成 SQL、执行并给结论。

**落地文件**
- `src/agent/dataset.js` 数据仓库快照：7 张表 / 13,106 行（销售 12,890、采购 132、库存 48、健康度 12、维度 12/8/4），固定种子 mulberry32(20261123)，快照日 2026-11-23。
- `src/agent/schema.js` 语义层：`TABLE_DOCS` + `METRICS`（22 个指标，含表达式与口径文案）+ `DIMENSIONS` + 示例问题 + 能力边界。
- `src/agent/nl2sql.js` 问题 → plan → SQL；`sqlEngine.js` 只读 SQL 执行器（SELECT/JOIN/GROUP BY/HAVING/CASE WHEN/聚合/标量函数）；`insight.js` 结论；`index.js` 编排（`ask()` / `runCustom()`）。
- `src/views/agent/query.vue` + `src/components/agent/AgentChart.vue`；路由 `/agent/query`。
- `tests/agent.eval.mjs`（27 条，Node 直跑）；`docs/智能取数Agent-设计说明.md`。

**关键决策**
1. 不把口径交给大模型：语义层固化口径，解析器只做映射；大模型只作为可替换解析器（产出同结构 plan）。
2. 「SQL 真跑」是可信度来源：自研只读引擎，结果带 scanned/elapsedMs 展示在页面上。
3. 库存周转 / 售罄需要跨事实表聚合 → 预聚合 `dm_sku_stock_health`（DM 层），避免业务方写子查询。
4. 指标匹配按 METRICS 定义顺序做「span 占用 + 优先级」，否则「库存周转天数」会被 on_hand 的 `/库存/` 抢走主题。
5. 权限快照键升级为 `xy_erp_post_perms_v2`：不升 key 老账号看不到新页面（整块菜单消失）。

**踩坑**
- 注释里写 `*/%` 会提前闭合块注释，导致整文件 SyntaxError（sqlEngine 优先级注释）。
- JS 字符串 `'[\s\S]*'` 中 `\s` 被吞成 `s`，LIKE 永远匹配失败；必须写 `'[\\s\\S]*'`。
- 中文 `localeCompare('zh-CN')` 的「本期/上期」顺序不可依赖，改按 `MIN(日期) DESC` 排序。
- 图表金额混排「万 / 元」很丑：`fmtValue` 阈值统一到 1 万，表格另用完整数值格式化。

**数据口径影响**
- 全站权限数从 84 项 / 22 页变为 **89 项 / 23 页**（新增 5 个操作），文档与测试里引用旧数字需同步。
- 默认时间口径：销售/采购「近 30 天」，库存类「快照日」；本月 = 11-01 至快照日 11-23（非自然月全月）。

**验证**
- `node tests/agent.eval.mjs` → 27/27 通过（语义、口径复算、安全边界、12 条推荐问题 + 32 条追问冒烟）。
- `npm run build` 通过；1440 宽无横向溢出；仓管/运营/售后/系统管理员四种职位菜单与提问权限均已实测。

5. 迭代回归 → `docs/评测报告-经营数据问答Agent.md` + `docs/版本变更记录-经营数据问答Agent.md`

**三轮数字**：v1 37 条 54.1%（17 失败）→ v2 40 条 100% → v2.1 48 条 100%（144 次执行，平均 7ms）

**关键决策**
- 安全不写在提示词里：权限、只读、白名单全部落在工具 `run_readonly_sql`，改 SQL 也绕不过（总监缺 platform IN 直接拒）
- 表白名单前置到 SQL 解析之前，否则 `information_schema.tables` 报「语法错误」，看起来像用户写错
- 拒答必须结构化：code 供评测断言，policy 对应边界条款，suggestions 变可点替代问法
- 多轮用「半句拼接」而不是状态机：可解释、成本低；代价是一句里换主题会带旧指标（已列为局限）
- 中文数字必须解析：业务方说「前三个」「近一周」，只写 `\d+` 会静默答错
- 找不到指标不能静默降级（复购率/目标完成率），否则界面上看不出「答非所问」

**踩坑**
- `dist/` 每次 build 会被清空：放在 dist 里的截图辅助页要先放 `.tmp/` 再 cp 回来
- 预览服务不能用 `(cmd &)` 后台化，Bash 工具结束会杀掉进程 → 必须 `run_in_background: true`
- 无头 Edge 的 `--virtual-time-budget` 会让 `performance.now()` 不再推进，页面上的耗时全显示 <1ms（截图假象，Node 实跑是 10~40ms）
- 之前的 `tests/agent.eval.mjs` 已不存在，设计说明里 27 条的引用全部作废，已改为 `tests/eval/`
- `tests/run-all.mjs` 依赖 CDP 调试端口，本地直接跑会报「未找到可调试的页面目标」，与本次改动无关
