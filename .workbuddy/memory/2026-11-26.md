## 14:28 添加货品支持上传图片
- 需求：供应商管理 → 添加货品弹窗要能传货品图片（此前「图片」列只有灰底「图」占位）。
- 无后端，实现：`el-upload :auto-upload="false"` + FileReader → canvas 压缩到 160px 边长（JPEG 0.82）
  → dataURL 存 `goods.image`；限 JPG/PNG/WebP、单张 ≤5MB；选填、可移除；
  `onPickImage` 里 `imgUpRef.clearFiles()` 保证重选同一张也能触发。
- 关键坑（同单位那次）：`supplier.addGoods()` 是白名单，**必须加 `image`**，否则上传后保存即丢。
- 连带：供应商货品列表缩略图 34px；`GoodsPicker` 加图片列（弹窗 860→900，其余列宽压缩）；
  `create.vue` 明细显示图、选货带 `image`，但 **submit 不把 image 写进采购单**
  （base64 每单重复存会撑爆 localStorage），因此 submit 的 items 改成显式字段白名单。
- 提交：`1f12cbf feat(purchase): 添加货品支持上传图片`（未 push）。
- 相关约定：凡是走 `addGoods` / 采购 items 的新字段，都要检查两处白名单，否则静默丢失。
