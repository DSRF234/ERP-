# 开发规范

## 一、页面结构唯一模板

所有列表页三段式，不允许发明第四种：

```
PageHeader（标题 + 操作）
筛选区（搜索 + 下拉 + 查找/重置）
.card 表格
```

用 `TablePage` 组件即自动满足；自定义页（订单、售后、看板、权限）参照 `views/order/list.vue` 的结构。

## 二、状态标签

| 语义 | el-tag type |
|---|---|
| 已完成 / 正常 | success（绿 #1E8E5A） |
| 进行中 / 部分 | warning（橙 #B26A00） |
| 异常 / 超时 | danger（红 #C0392B） |
| 中性 | info（灰 #8A949E） |

## 三、金额

- 一律 `money()` 输出，`￥` + 千分位 + 两位小数
- 空值与 0 严格区分：空值 `—`，0 显示 `￥0.00`
- 负金额（退款）保留负号

## 四、时间

- 列表显示 `YYYY-MM-DD HH:mm`
- 剩余时间用 `timeLeft()`：已超（红）/ 快超 <10h（橙）/ 剩余（灰）

## 五、禁止事项

- ❌ 引入新的 UI 库或 CSS 框架
- ❌ 在组件里写全局 `<style>`
- ❌ 每个页面重建一套表头样式
- ❌ 直接改 `node_modules` 里的 Element 样式文件（改写 theme.css）
- ❌ 提交 `node_modules` / `dist`
