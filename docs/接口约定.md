# 接口约定

## 一、统一响应体

所有接口返回同一结构，前端在 `api/request.js` 里统一拆包：

```json
{
  "code": 0,
  "message": "ok",
  "data": { }
}
```

- `code = 0` 表示成功，非 0 表示业务异常
- 分页数据放在 `data.list` 与 `data.total`

## 二、分页参数

请求：

```
GET /api/orders?page=1&pageSize=20&keyword=&status=
```

响应：

```json
{ "code": 0, "data": { "list": [], "total": 12486 } }
```

## 三、错误码

| code | 含义 | 前端处理 |
|---|---|---|
| 0 | 成功 | — |
| 1001 | 参数错误 | 提示 message |
| 1002 | 未登录 | 跳登录页 |
| 1003 | 无权限 | 提示且不跳转 |
| 2001 | 业务校验失败 | 提示 message |
| 5000 | 服务端异常 | 提示“系统繁忙” |

## 四、现有接口清单

| 方法 | 路径 | 说明 | 状态 |
|---|---|---|---|
| GET | `/api/dashboard/kpi` | 看板指标 | mock |
| GET | `/api/dashboard/trend` | 销售趋势 | mock |
| GET | /api/reconciliation | 对账列表 | mock |
| GET | /api/reconciliation/:id | 对账详情 | mock |

后端就绪后，把 `src/api/index.js` 中对应函数改为：

```js
export const getDashboard = () => get('/dashboard/kpi')
```

**页面代码不需要任何改动。**

## 五、字段命名

- 一律小驼峰：`orderNo`、`settleAmount`、`createdAt`
- 金额字段单位统一为「元」，浮点两位；不要传「分」
- 时间字段统一 `YYYY-MM-DD HH:mm:ss` 字符串
- 枚举字段传英文码（`part` / `ok` / `miss`），前端负责翻译成中文
